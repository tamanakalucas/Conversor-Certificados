Ferramenta local de certificados

Conversor de Certificados

Converta entre PFX/P12, PEM, CRT, CER, KEY e JKS diretamente no navegador. Carregue um certificado, escolha o formato de saída e baixe o arquivo convertido.

🔒
Tudo roda localmente. A conversão acontece inteiramente no seu navegador com a biblioteca node-forge — nenhum arquivo, senha ou chave privada é enviado para qualquer servidor.

Escolha como seu certificado está empacotado hoje.

2Conteúdo detectado

Marque qual certificado é o principal (leaf) e quais entram na cadeia exportada.

3Formato de saída

.PEM
Texto Base64, cadeia + chave opcional
.CRT
Certificado único, texto Base64
.CRT (DER)
Certificado único, binário
.CER
Certificado único, texto Base64
.CER (DER)
Certificado único, binário
.PFX / .P12
Pacote com chave privada protegido por senha
.JKS
Truststore Java (apenas certificados)
.KEY
Somente a chave privada
Requer uma chave privada carregada na etapa 1.
Gera um truststore (somente certificados públicos). O formato JKS para entradas com chave privada usa um algoritmo proprietário da Oracle não reimplementado aqui — veja o comando equivalente abaixo.
Preciso de um JKS com a chave privada → 
keytool -importkeystore \
  -srckeystore certificado.pfx -srcstoretype PKCS12 \
  -destkeystore certificado.jks -deststoretype JKS
Requer uma chave privada carregada na etapa 1. Se uma senha for definida, a chave é exportada como PKCS#8 criptografado (independente da opção de formato acima).
